# consultiolabs.de

Website von consultio labs. Wird über GitHub Pages veröffentlicht.

- `index.html`: Startseite
- `impressum.html`: Impressum
- `assets/`: Bilder, Logo und Schriften
- `toolbox/`: Neos Projekt-Toolbox (Web-App, offline-fähig). Bei Änderungen an der Toolbox in `toolbox/sw.js` die Cache-Version erhöhen.
